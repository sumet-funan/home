# สีตรงกันไหม? – เว็บเทียบสีของขนม/เครื่องดื่ม

เว็บแอปภาษาไทยสำหรับเกม "ซื้อขนมหรือเครื่องดื่มคนละ 3 อย่าง แล้วมาเทียบสีกัน" ผู้เล่น 2–6 คนใช้มือถือเครื่องเดียว ถ่ายรูปของแต่ละชิ้น แอปหาสีหลักของบรรจุภัณฑ์ให้เอง แล้วบอก **% ความเหมือน** ของทุกคู่ข้ามผู้เล่น

เปิดใช้: https://sumet-funan.github.io/home/image-color-diff/

## วิธีเล่น

1. ใส่ชื่อผู้เล่น (2–6 คน) เลือกจำนวนชิ้นต่อคน (1–5 ค่าเริ่มต้น 3)
2. ถ่ายรูปหรือเลือกรูปจากคลังรูปทีละชิ้น ให้สินค้าอยู่เต็มกรอบกลางจอ และถ่ายทุกชิ้นที่จุดเดียวกัน แสงเดียวกัน
3. แอปแสดงสีหลักและสีเด่นได้สูงสุด 3 สี พร้อมชื่อสีภาษาไทย ถ้าสีไม่ตรงให้ถ่ายใหม่
4. กด "ดูผล" ดูคู่ที่สีตรงกัน (ค่าเริ่มต้น ≥ 80% ปรับได้ 50–95%) สรุปของแต่ละคน และกด "แชร์ผล" เพื่อส่งรูปสรุปเข้าแชต

ข้อมูลทั้งหมดอยู่ในเครื่อง (localStorage เก็บแค่เกมล่าสุด) ไม่มีการส่งรูปออกไปไหน

## คิด % ยังไง

- แปลงสีเป็น CIELAB (D65) แล้ววัดระยะห่างของสีหลักด้วยสูตร **CIEDE2000 (ΔE2000)**
- % ความเหมือน = 100 × (1 − ΔE / 50) ตัดให้อยู่ในช่วง 0–100 ดังนั้น ΔE 0 = 100%, ΔE 10 = 80%, ΔE ≥ 50 = 0%
- "ชุดสี %" เป็นตัวเลขรอง: แต่ละสีในชุดหาสีที่ใกล้สุดในอีกชุด ถ่วงตามสัดส่วนพื้นที่ แล้วเฉลี่ยสองทาง

การหาสีหลักจากรูป (`extractPalette`): ใช้ส่วนกลาง 60% ของรูปและถ่วงน้ำหนักเข้าหาจุดกลาง, ตัดจุดสะท้อนแสงสีขาวออก (ยกเว้นสินค้าเป็นสีขาวเกินครึ่ง), จัดกลุ่มสีด้วย k-means ใน Lab, รวมเฉดที่ใกล้กัน (ΔE2000 < 6), และลดน้ำหนักสีที่อยู่ตามขอบรูปมากกว่ากลางรูป (พื้นโต๊ะ ผนัง) โดยเฉพาะสีกลางๆ อย่างเทา/ขาว/ดำ ไม่มีการปรับสมดุลแสง

## โครงไฟล์

```
index.html          หน้าเว็บ
css/style.css       สไตล์ทั้งหมด รวมโหมดมืด
js/color.js         คณิตศาสตร์สี: Lab, ΔE2000, %, ชื่อสีไทย, หาสีหลักจากรูป (ไม่แตะ DOM)
js/app.js           หน้าจอเล่นและหน้าผล, เก็บเกมใน localStorage
js/share.js         วาดรูปสรุปผลสำหรับแชร์
test/color.test.mjs ชุดทดสอบ (รวมค่ามาตรฐาน ΔE2000 34 คู่ของ Sharma et al. 2005)
```

## พัฒนา

HTML/CSS/JS ล้วน ไม่มี build step ต้องเปิดผ่าน HTTP เพราะใช้ ES modules เช่น `npx serve .` ที่ root ของ repo แล้วเปิด `/image-color-diff/`

รันชุดทดสอบ (Node 18 ขึ้นไป ไม่ต้องติดตั้งอะไรเพิ่ม):

```
node --test image-color-diff/test
```
