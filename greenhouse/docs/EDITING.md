ทุกอย่างในเว็บสร้างจากข้อมูล 3 ไฟล์ใน `src/data/` แก้ที่นี่ที่เดียว ฉาก 3 มิติ ป้าย การ์ด และแอนิเมชันจะเปลี่ยนตามเอง

| อยากแก้ | ไฟล์ | ตัวอย่าง |
| --- | --- | --- |
| ตัวเลขขนาด ตำแหน่งรู จำนวนชิ้น | `src/data/spec.ts` กลุ่ม `SPEC` | `rafter.holes.tie: 876` |
| ค่าที่สเปกเขียนไว้ 2 แบบ | `src/data/spec.ts` กลุ่ม `DECISIONS` | `gablePostLength: 2325` |
| ค่าที่สมมติเพื่อวาดรูป | `src/data/spec.ts` กลุ่ม `ASSUMED` | `ground.riseEast: 50` |
| ชื่อชิ้นส่วนและข้อความบนการ์ด | `src/data/parts.ts` | `name: 'คานรัด'` |
| ข้อความขั้นตอน คำเตือน เช็กก่อนไปต่อ | `src/data/steps.ts` | `text`, `warn`, `checks` |
| มุมกล้องของแต่ละขั้น | `src/data/steps.ts` › `CAMERAS` | `slabTie` |

## หลังแก้ทุกครั้ง

```
npm test
```

test ตรวจว่ารูทุกรูที่น็อตผ่านยังตรงกันภายใน ±1 มม. ความยาวน็อตพอ จำนวนชิ้นตรงกับตาราง และทุกขั้นตอนอ้างถึงชิ้นที่มีจริง
ถ้าแก้ตัวเลขแล้ว test ฟ้อง แปลว่าตัวเลขขัดกับชิ้นอื่น เช่น เปลี่ยนรูจันทันแล้วรูไม่ตรงฉากสัน ให้แก้ชิ้นที่เกี่ยวข้องให้ตรงกันก่อน

## เพิ่มขั้นตอน

เพิ่ม object ใน `STEPS` (ใน `src/data/steps.ts`) ตามลำดับ ใช้ id รูปแบบ `step-<ระยะ>-<ข้อ>`
- `add` / `remove`: ป้ายของชิ้นที่ปรากฏหรือหายไป (ดูป้ายได้จาก `tag` ใน `geometry.ts` หรือ `SCENE_TAGS`)
- `camera`: ชื่อมุมกล้องใน `CAMERAS`
- `zoom`: id ของน็อตที่จะซูมให้เห็นการใส่ (ดู `JOINTS` ใน `geometry.ts`)

ถ้าเปลี่ยนจำนวนขั้นในระยะใด ให้แก้ตัวเลขใน test "id ไม่ซ้ำ เรียงตามระยะ" ให้ตรงด้วย

## แอนิเมชัน

แอนิเมชันทุกขั้นสร้างจากข้อมูลใน `STEPS` เอง (กล้อง → ชิ้นใหม่ปรากฏ → ซูมน็อต → ป้ายชี้จุด) แก้ได้ที่ `src/anim/`

| อยากแก้ | ไฟล์ |
| --- | --- |
| ความเร็ว ระยะเวลาแต่ละช่วง ระยะกล้องตอนซูมน็อต | `src/anim/config.ts` › `TIMING`, `ZOOM_DISTANCE` |
| ชิ้นไหนลอยจากกองวัสดุ / หล่นลงมา / ขุด / ลากเส้น | `src/anim/config.ts` › `EXACT` (ค่าเริ่มต้นของชิ้นเหล็ก = ลอยจากกองวัสดุ) |
| ป้ายชี้จุดและเส้นวัดระยะของแต่ละขั้น | `src/anim/notes.ts` › `CALLOUTS`, `DIMS` (ใช้ id ของขั้น) |
| ลำดับช่วงในหนึ่งขั้น และแอนิเมชันพิเศษ | `src/anim/timeline.ts` |
| หน้าตาสายยางระดับ ขีด-เจาะรู ขันน็อต | `src/scene/Specials.tsx` |

ลิงก์ไปขั้นใดขั้นหนึ่งได้ด้วย `#step-<ระยะ>-<ข้อ>` เช่น `http://localhost:5173/#step-3-4` และ `#summary` คือหน้าสรุป
ระหว่างพัฒนา (`npm run dev`) เปิดคอนโซลแล้วใช้ `__player.seek(0.5)` เลื่อนไปครึ่งขั้น หรือ `__player.finish()` ข้ามไปจบขั้น

ถ้าเครื่องตั้งค่า "ลดการเคลื่อนไหว" (prefers-reduced-motion) ทุกขั้นจะแสดงเป็นภาพนิ่งตอนจบขั้นแทนแอนิเมชัน
