# โรงเรือนผักสลัด 3×6 ม. — คู่มือสร้างแบบ 3 มิติทีละขั้น

เว็บภาษาไทยที่สอนมือใหม่สร้างโรงเรือนหลังคาจั่วขนาด 3×6 ม. ด้วยเหล็กกล่องกัลวาไนซ์และน็อต M8 ตั้งแต่ตีผังจนวางชั้นวางกล่องโฟม
ทุกขั้นเป็นแอนิเมชัน 3 มิติ:
- **ชิ้นใหม่:** เป็นสีส้ม ลอยจากกองวัสดุเข้าที่
- **น็อต:** กล้องซูมให้เห็นการเสียบ ใส่แหวน และขันจากด้านที่ถูก
- **จบแต่ละระยะ:** มีการ์ด "เช็กก่อนไปต่อ" ให้ติ๊ก

ตัวเลขทุกตัวมาจาก [docs/greenhouse-spec.md](docs/greenhouse-spec.md) ค่าที่ต้องสมมติเพื่อวาดภาพรวมไว้ใน [ASSUMPTIONS.md](ASSUMPTIONS.md)

## รันบนเครื่อง

ต้องมี Node.js 18 ขึ้นไป

```
npm i
npm run dev
```

เปิดลิงก์ที่ขึ้นในเทอร์มินัล (ปกติ http://localhost:5173)

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm run dev` | เปิดเว็บสำหรับพัฒนา แก้ไฟล์แล้วหน้าเว็บเปลี่ยนตาม |
| `npm test` | ตรวจตัวเลขและข้อมูล (รูน็อตตรงกัน ±1 มม. จำนวนชิ้นตรงตาราง ขั้นตอนอ้างชิ้นที่มีจริง ฯลฯ) |
| `npm run build` | สร้างเว็บสำหรับขึ้นจริงไว้ที่ `dist/` |
| `npm run preview` | เปิดดู `dist/` ที่ build แล้ว |

## ใช้งานเว็บ

- **ปุ่มเล่น:**
  - ⏮ ▶/⏸ ⏭ ↺ = ขั้นก่อนหน้า เล่น/หยุด ขั้นถัดไป และเล่นขั้นนี้ซ้ำ
  - 0.5× 1× 2× = ความเร็ว
  - แถบเลข 0–7 กระโดดไปต้นระยะนั้น และปุ่ม "สรุป" ไปหน้าสรุป
- **ลิงก์ตรงไปขั้นใดก็ได้:** เติมท้ายลิงก์ เช่น `#step-4-3` หรือ `#summary` ส่งต่อให้คนอื่นเปิดขั้นเดียวกันได้
- **หมุนกล้อง:** ลากหมุนหรือซูมได้ทุกเมื่อ แล้วกด "กลับมุมแนะนำ" เพื่อกลับมุมกล้องของขั้น
- **สวิตช์มุมมอง:**
  - พลาสติก-มุ้ง = ซ่อนหรือแสดงแผ่นคลุม
  - ป้ายชื่อ
  - ระยะ = เส้นวัดขนาดหลัก
  - X-ray = ทำเหล็กโปร่งให้เห็นน็อตด้านใน
- **การ์ดชิ้นส่วน:** แตะชิ้นส่วนแล้วการ์ดบอกขนาด รู จำนวน และขั้นที่ใช้ชิ้นนั้น
- **เช็กลิสต์:** ข้อที่ติ๊กไว้ในการ์ดเช็กและเช็กลิสต์สุดท้ายจำไว้ในเบราว์เซอร์เครื่องนั้น
- **ลดการเคลื่อนไหว:** ถ้าเครื่องตั้ง "ลดการเคลื่อนไหว" (prefers-reduced-motion) จะเห็นภาพนิ่งตอนจบแต่ละขั้นแทนแอนิเมชัน

## ขึ้นเว็บจริง

`vite.config.ts` ตั้ง `base: './'` ไว้แล้ว เว็บจึงทำงานได้ทั้งที่โดเมนหลักและในโฟลเดอร์ย่อย

### GitHub Pages (วิธีที่ใช้อยู่ตอนนี้)

เว็บออนไลน์อยู่ที่ **https://sumet-funan.github.io/home/greenhouse/app/**
GitHub Pages ของ repo นี้เสิร์ฟไฟล์จาก branch `main` ตรง ๆ จึงต้อง commit ไฟล์ที่ build แล้วไว้ในโฟลเดอร์ `app/`

ทุกครั้งที่แก้เว็บแล้วอยากให้ขึ้นออนไลน์:

```
npm test
npm run build:pages
```

แล้ว commit ทั้งโค้ดและโฟลเดอร์ `app/` แล้ว push ขึ้น `main` ประมาณ 1 นาทีเว็บจะอัปเดต
(ถ้าลืม `npm run build:pages` เว็บออนไลน์จะยังเป็นเวอร์ชันเก่า)

### GitHub Pages (อัตโนมัติด้วย GitHub Actions — ทางเลือก)

ถ้าไม่อยากเก็บไฟล์ build ใน repo ให้ใช้ workflow แทน แต่ต้องเปลี่ยน Pages เป็นโหมด GitHub Actions
ซึ่ง workflow ต้องเผยแพร่โปรเจกต์อื่นใน repo (Math Lesson, Bird Scarer) ด้วย ไม่อย่างนั้นโปรเจกต์เหล่านั้นจะหายจากเว็บ

โปรเจกต์นี้อยู่ในโฟลเดอร์ `greenhouse/` ของ repo ไฟล์ workflow ต้นแบบอยู่ที่ [docs/greenhouse-pages.yml](docs/greenhouse-pages.yml)

1. ใน GitHub เปิด repo → **Add file → Create new file** ตั้งชื่อ `.github/workflows/greenhouse-pages.yml` แล้ววางเนื้อหาจาก [docs/greenhouse-pages.yml](docs/greenhouse-pages.yml) กด Commit (ทำครั้งเดียว ทำผ่านหน้าเว็บ GitHub ได้โดยไม่ต้องให้สิทธิ์ workflow กับเครื่องนี้)
2. เปิด repo → **Settings → Pages** → ช่อง **Source** เลือก **GitHub Actions** (ทำครั้งเดียว)
3. push ขึ้น branch `main` เมื่อมีไฟล์ใน `greenhouse/` เปลี่ยน workflow จะทำต่อเอง:
   - รัน `npm ci`
   - รัน `npm test` ถ้า test ไม่ผ่าน จะไม่ขึ้นเว็บ
   - รัน `npm run build`
   - เอา `dist/` ขึ้น GitHub Pages
4. ลิงก์เว็บอยู่ที่แท็บ **Actions** ในงาน deploy หรือที่ Settings → Pages (รูปแบบ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`)

ถ้าจะสั่งขึ้นเว็บเองโดยไม่ push ไปที่แท็บ Actions → เลือก workflow นี้ → **Run workflow**

> repo หนึ่งมีเว็บ GitHub Pages ได้เว็บเดียว ถ้าต้องการขึ้นโปรเจกต์อื่นใน repo นี้ด้วย ต้องรวมไว้ใน build เดียวกัน หรือแยก repo

### Vercel

1. Import repo นี้ใน Vercel
2. **Root Directory** = `greenhouse`
3. Framework Preset = **Vite** (Build Command `npm run build`, Output Directory `dist`)

### ที่อื่น ๆ

รัน `npm run build` แล้วอัปโหลดทุกไฟล์ใน `dist/` ขึ้นเว็บโฮสติ้งแบบไฟล์นิ่งได้เลย ไม่ต้องมีเซิร์ฟเวอร์

## โครงสร้างไฟล์

```
src/data/       ข้อมูลทั้งหมด (แก้ที่นี่)
  spec.ts         ตัวเลขจากสเปก + ค่าที่ตัดสินใจ + ค่าที่สมมติ
  parts.ts        ชื่อ ขนาด จำนวนของชิ้นส่วนแต่ละชนิด
  geometry.ts     คำนวณตำแหน่งชิ้น รู น็อต หลุม แผ่นคลุม (หน่วย มม.)
  steps.ts        ขั้นตอน 54 ขั้น ระยะ 0–7 เช็กก่อนไปต่อ มุมกล้อง
  usage.ts        ชิ้นไหนใช้ในขั้นไหน
src/anim/       แอนิเมชัน (ไทม์ไลน์ GSAP ต่อขั้น ป้ายชี้จุด เส้นวัด)
src/scene/      ฉาก 3 มิติ (react-three-fiber)
src/ui/         แผงขั้นตอน การ์ดเช็ก ที่เก็บค่าที่ติ๊ก
docs/EDITING.md วิธีแก้ไขข้อมูลแต่ละเรื่อง
```

แก้ตัวเลข ข้อความ หรือมุมกล้องตามวิธีใน [docs/EDITING.md](docs/EDITING.md) แล้วรัน `npm test` ทุกครั้ง
