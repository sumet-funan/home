คู่มือ DIY ทีละขั้นตอน

สร้างเครื่องไล่นกพิราบ พลังงานโซลาร์

ESP32 + เรดาร์ LD2410C + ลำโพงฮอร์น ตรวจจับเมื่อนกมาเกาะแล้วเปิดเสียงไล่ ใช้ไฟจากแผงโซลาร์ ไม่ต้องเดินสายไฟบ้าน

  • งบประมาณ~3,900 บาทไม่รวมเครื่องมือ
  • เวลาประกอบ~1 วันไม่รวมรอสเปรย์แห้ง/ทดสอบ 24 ชม.
  • ความยากปานกลางต้องบัดกรีเป็น
เริ่มทำตามขั้นตอน ดูรายการของที่ต้องซื้อ

1ภาพรวมระบบ

ทำงานอย่างไร

  1. เรดาร์ LD2410C ตรวจจับสิ่งเคลื่อนไหวในระยะ 1.5–2 ม. รอบจุดที่นกชอบเกาะ
  2. ESP32 ยืนยันว่าเจอจริง ตรวจช่วงเวลาทำงานและแรงดันแบต แล้วเปิดแอมป์
  3. DFPlayer สุ่มเล่นเสียงเหยี่ยว/นกตกใจจากการ์ด SD ส่งเข้าแอมป์ PAM8610 ออกลำโพงฮอร์น
  4. เล่นจบ ESP32 ปิดแอมป์เพื่อประหยัดไฟ

ระบบไฟ

แผงโซลาร์ 20W ชาร์จแบต LiFePO4 12V ผ่านชาร์จเจอร์ ขั้ว LOAD ของชาร์จเจอร์จ่ายไฟให้วงจร (และตัดไฟเองเมื่อแบตต่ำ) แอมป์ใช้ 12V โดยตรง ส่วน ESP32 เรดาร์ และ DFPlayer ใช้ 5V จาก MP1584

GND ของวงจรทั้งหมดต่อจากขั้ว LOAD− ของชาร์จเจอร์ ไม่ต่อจากขั้วลบแบตโดยตรง

    4ผังต่อสาย

    ลากเพื่อเลื่อนดู ใช้สองนิ้วถ่าง ปุ่ม + / − หรือ Ctrl + ล้อเมาส์เพื่อซูม กด "พอดีจอ" เพื่อดูทั้งผัง

    ไฟเลี้ยง

    • แผงโซลาร์ → ขั้ว PV ของชาร์จเจอร์
    • แบต LiFePO4 → ฟิวส์ 5A → ขั้ว BAT ของชาร์จเจอร์
    • ขั้ว LOAD → ฟิวส์ 2A → (1) แอมป์ PAM8610 ขา 12V  (2) MP1584 IN
    • MP1584 OUT 5.0V → ESP32 VIN, LD2410C VCC, DFPlayer VCC
    • GND ทุกตัวต่อร่วมกัน (ที่ขั้ว LOAD−)

    6ตั้งค่าเรดาร์ LD2410C

    1. ติดตั้งแอป HLKRadarTool จาก Google Play หรือ App Store (ผู้พัฒนา Hi-Link) และเปิด Bluetooth กับ Location บนมือถือ
    2. จ่ายไฟ 5V ให้ LD2410C เปิดแอป จะเห็นอุปกรณ์ชื่อขึ้นต้นด้วย HLK-LD2410 แตะเพื่อเชื่อมต่อ (ถ้าถามรหัส ค่าเริ่มต้นคือ HiLink)
    3. หน้าแรกจะเห็นสถานะ Moving / Stationary / None และระยะเป้าหมาย ลองโบกมือดูว่าค่าเปลี่ยน
    4. เข้าหน้าตั้งค่า (Parameter settings) กำหนด:
      • Max motion gate = 2–3
      • Max static gate = 2–3
      • Unmanned duration = 1 วินาที
      กด Save / Send ทุกครั้งหลังแก้
    5. เปิด Engineering mode เพื่อดูกราฟพลังงานของแต่ละ gate แบบ realtime ตอนที่ไม่มีอะไรเคลื่อนไหวจดค่าพลังงานพื้นหลังของแต่ละ gate
    6. ตั้งค่าเกณฑ์ (threshold) ของแต่ละ gate ให้สูงกว่าพลังงานพื้นหลังประมาณ 10–15 ค่าเกณฑ์ยิ่งต่ำ ยิ่งไว gate ที่ไกลกว่าระยะที่ต้องการให้ตั้งเป็น 100 (ปิด)
    7. ปิด Engineering mode แล้วทดสอบ: โยนผ้าหรือของเล็กๆ ผ่านจุดที่นกเกาะ เรดาร์ควรตรวจจับ แต่ไม่ควรตรวจจับใบไม้หรือรถที่อยู่ไกลออกไป
    8. เมื่อตั้งค่าเสร็จ ปิด Bluetooth ของโมดูลในแอปได้ (ถ้าต้องการ) เพื่อไม่ให้คนอื่นเชื่อมต่อ
    ระยะของแต่ละ gate (ความละเอียด 0.75 ม.)
    Gateระยะใช้กับ
    00 – 0.75 ม.นกเกาะชิดกล่อง
    10.75 – 1.5 ม.ขอบบัวใกล้
    21.5 – 2.25 ม.ขอบบัว/มุมหลังคา (ค่าแนะนำสูงสุด)
    32.25 – 3.0 ม.ใช้เมื่อติดตั้งไกลจากจุดเกาะ

    💡 ขา OUT ของ LD2410C จะเป็น HIGH เมื่อตรวจเจอ และกลับเป็น LOW หลังจากไม่มีอะไรเคลื่อนไหวนานเท่ากับ Unmanned duration

    7ทดสอบและแก้ปัญหา

    Serial ขึ้น "DFPlayer not found"
    • โค้ดจะลองเชื่อมต่อ 5 ครั้ง ถ้าไม่สำเร็จจะรีสตาร์ตเองแล้วลองใหม่ ถ้าเห็นข้อความนี้วนซ้ำ แปลว่ามีปัญหาจริง ให้ตรวจตามข้อด้านล่าง
    • สลับสาย TX/RX: DFPlayer TX → GPIO 16, GPIO 17 → 1kΩ → DFPlayer RX
    • ตรวจว่ามีตัวต้านทาน 1kΩ และค่าถูกต้อง (น้ำตาล-ดำ-แดง)
    • การ์ด SD ต้องฟอร์แมตเป็น FAT32 และเสียบแน่น
    • ชื่อไฟล์ต้องเป็น 0001.mp3, 0002.mp3 … อยู่ที่ root ของการ์ด
    • ลองเปลี่ยนเป็น DFPlayer ตัวสำรอง (บางล็อตมีชิปต่างรุ่น)
    เล่นได้ (Serial แจ้งว่าเล่น) แต่ไม่มีเสียงออกฮอร์น
    • ขา SD ของแอมป์: ลองสลับค่า AMP_ON_LEVEL เป็นค่าตรงข้าม
    • GND ของ DFPlayer กับ GND ของแอมป์ต้องต่อร่วมกัน
    • หมุนปุ่มวอลุ่มบนแอมป์ขึ้น (บางรุ่นหมุนสุดซ้ายคือเงียบ)
    • วัดไฟที่ขา 12V ของแอมป์ ต้องได้ 12–14V
    • ตรวจว่าต่อ IN และ OUT เป็นช่องเดียวกัน (L กับ L หรือ R กับ R)
    ดังเองบ่อยโดยไม่มีนก
    • ลด max gate หรือเพิ่มค่าเกณฑ์ (ลดความไว) ในแอป HLKRadarTool
    • หันเรดาร์หนีใบไม้ กิ่งไม้ ผ้าที่ตากไว้ และถนน
    • เพิ่มค่า RADAR_CONFIRM_MS ทีละ 200–500 ms ให้ต้องเจอนานขึ้นก่อนเล่นเสียง
    • ตรวจว่ากล่องยึดแน่น ไม่สั่นตามลม
    ไม่ตรวจจับนก
    • เพิ่มความไว (ลดค่าเกณฑ์) ของ gate 0–2
    • ย้ายจุดติดตั้งให้ใกล้จุดที่นกเกาะมากขึ้น (ไม่เกิน 2 ม.)
    • ตรวจว่าไม่มีโลหะ ฟอยล์ หรือแบตบังด้านหน้าเรดาร์ในกล่อง
    • ดูใน Engineering mode ว่าตอนนกเกาะ พลังงาน gate ไหนขึ้น แล้วตั้งเกณฑ์ gate นั้นให้ต่ำลง
    แบตลดลงเรื่อยๆ
    • ตรวจว่าแผงไม่โดนเงา (แม้เงาแค่บางส่วนก็ทำให้ชาร์จลดลงมาก) และเช็ดฝุ่นบนแผง
    • ชาร์จเจอร์ต้องตั้งเป็นโหมด LiFePO4
    • ลดระดับเสียง (VOL_MAX) หรือความถี่ในการเล่น และย่นช่วงเวลาทำงาน
    • ตรวจว่าแอมป์ปิดเมื่อไม่ได้เล่น (ขา SD ทำงาน)
    มีเสียงป๊อปตอนเปิดแอมป์
    • เพิ่มค่า delay ในฟังก์ชัน ampOn() ให้แอมป์นิ่งก่อนเริ่มเล่นเสียง
    • ตรวจว่า GND ร่วมกันดี และสายสัญญาณ DAC_R สั้น
    นกเริ่มชิน กลับมาเกาะอีก
    • เพิ่มไฟล์เสียงใหม่ๆ และสลับชุดเสียงทุก 2–4 สัปดาห์
    • ใช้ร่วมกับหนามกันนกหรือตาข่ายในจุดที่นกชอบเกาะ
    • ทำความสะอาดคราบมูลนกในจุดเดิม เพราะนกจะกลับมาที่ที่มีร่องรอยเดิม
